# 0007 発話音声とテキストの近さは Gradio アプリで手軽に試す

- 日付: 2026-11-06
- ステータス: 採用

## 背景
会話のような発話音声の埋め込みが、書き起こしテキストにどれだけ近いかを調べたい。最初に検討したのは、日本語の対話コーパス（IngCrowd Japanese Themed Casual Conversation Corpus、CC BY-NC 4.0）を発話単位に切り出し、検索精度などを集計する実験だった。ただ、実験の規模が大きくなるため、まずは手元で感触をつかむことを優先した。

## 決定
- Gradio で簡単なブラウザアプリを作る。マイク録音と自由入力のテキストから、その場でコサイン類似度を出す
- モデルはこれまでと同じ Docker コンテナの GPU で動かし、ポートはホストの `127.0.0.1:7860` にだけ公開する
- 類似度は絶対値でなく、複数候補の中での順位と候補平均との差で示す（モダリティギャップのため）
- gradio は依存グループ `app` に分けて入れる（実験コードからは import しない）

## 保留
コーパスを使った定量評価（音声 → 書き起こしの R@1 / MRR、発話の長さ別の集計、ギャップ補正の効果）は、アプリで傾向を見てから必要に応じて実施する。
