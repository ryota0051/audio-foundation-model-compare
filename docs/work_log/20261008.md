## 追加: ESC-50 音声⇔音声検索によるモデル比較（`feature/step1b-esc50-retrieval`）

### 実施内容
- 公式 5 fold 交差検証で、4 fold を検索対象・1 fold をクエリにした k-NN 分類 / Precision@k / 線形プローブを実装・実行（全 5 モデル）

### 結果（5 fold 平均 ± 標準偏差, %）
| モデル | k-NN@1 | k-NN@5 | Precision@10 | 線形プローブ |
|---|---|---|---|---|
| EmbeddingGemma 2 | 70.2 ± 2.3 | 72.7 ± 2.4 | 56.6 ± 1.0 | 81.8 ± 1.3 |
| BEATs iter3 | 72.0 ± 2.1 | 70.6 ± 2.6 | 51.6 ± 1.5 | 88.3 ± 2.2 |
| BEATs iter3 L6 | 68.4 ± 2.6 | 67.7 ± 2.2 | 48.9 ± 1.6 | 86.2 ± 2.1 |
| BEATs iter3+ AS2M | 91.6 ± 2.3 | 90.8 ± 2.1 | 81.6 ± 0.5 | 95.9 ± 1.2 |
| BEATs iter3+ AS2M FT | 95.2 ± 0.9 | 95.6 ± 0.7 | 91.9 ± 0.5 | 96.6 ± 0.9 |
| （参考）EmbeddingGemma 2 ゼロショット | Top-1 27.4 | | | |

### 考察
- **EmbeddingGemma 2 の音声埋め込み自体はクラス情報をかなり持っている**（k-NN 70%, 線形プローブ 82%）。ゼロショット 27% との差は大きく、ESC-50 での弱さは主に**音声⇔テキストの対応付け側**にある
- ラベル不使用の BEATs iter3 と比べると k-NN はほぼ同等（@1 は全 fold で iter3 が 0〜3.5pt 上）、Precision@10 は EmbeddingGemma 2 が上、線形プローブは iter3 が 6.5pt 上
- AudioSet ラベル由来の BEATs（+AS2M, FT）は 90% 超。ESC-50 のクラスは AudioSet と重なるため有利な条件である点に注意
- DCASE とあわせると: EmbeddingGemma 2 は「何の音か」の検索では自己教師あり BEATs と同程度だが、同一機械内の正常/異常の微差では BEATs に劣る

### 実施内容

- **ハブ化は補正で大きく減る**（最多予測 244 → 163、未予測クラス 9 → 0）が、**最良 Top-1 の改善は +2.4pt（27.4 → 29.8%）にとどまる**

## 追加: CLAP（laion/larger_clap_general）との比較（`feature/clap`）

### 実施内容
- CLAP を backend として追加（ADR 0006）。入力サンプリングレートをモデル設定ごとに（CLAP 48kHz）、10 秒超は決定的な窓分割 + 平均

- 混同行列・UMAP・モデル比較の図表に CLAP を追加（分析スクリプトのゼロショット描画を複数モデル対応に）

### 結果
ESC-50（%）

| モデル | ゼロショット Top-1 | Top-5 | 音声 k-NN@1 | 線形プローブ |
|---|---|---|---|---|
| EmbeddingGemma 2 | 26.8（768）/ 27.4（512）| 59.4 | 70.2 | 81.8 |
| EmbeddingGemma 2 + 補正（列標準化, 256）| 30.0 | 63.3 | - | - |
| BEATs iter3 | - | - | 72.0 | 88.3 |
| BEATs AS2M FT | - | - | 95.2 | 96.6 |
| **CLAP** | **95.1** | **99.7** | **97.0** | **97.6** |

- CLAP の最良テンプレートは `This is a sound of {natural}.`。EmbeddingGemma 2 に同じ書式を使っても 26.6%（768）で改善せず → **差はテンプレートではなくモデルの対応付けの強さ**
- CLAP はハブ化がほぼない（最多予測 56 回、未予測 0）ため、ギャップ補正の効果もほぼない（95.1 → 95.35%）
- 平均コサイン類似度: 正解テキストと全テキスト平均の差は **CLAP 0.367（0.405 vs 0.038）/ EmbeddingGemma 2 0.037（0.697 vs 0.660）**。EmbeddingGemma 2 は音声どうし 0.829・テキストどうし 0.770 と埋め込みが狭い範囲に集中（異方性が強い）。CLAP は 0.258 / 0.324
- UMAP: CLAP は各クラステキストが該当音声クラスタの中に位置する。EmbeddingGemma 2 は 50 テキストが音声群から離れた 1 点

DCASE official score

| モデル | 最良条件 | 固定条件（whole / 全次元 / single / マハラノビス） |
|---|---|---|
| BEATs iter3 | **0.584** | 0.575 |
| 公式 MAHALA | 0.577 | - |
| 公式 MSE | 0.567 | - |
| CLAP | 0.561 | 0.543 |
| EmbeddingGemma 2 | 0.522 | 0.505 |

### 考察
- ESC-50 ゼロショットの EmbeddingGemma 2 の弱さは「音声⇔テキスト汎用モデルとして」明確に低い。ただし CLAP の値は ESC-50 の学習データ重複で楽観的な可能性がある（ADR 0006）。音声 k-NN では CLAP 97% / EmbeddingGemma 2 70% と、音声側の表現にも差がある
- DCASE では意味寄りのモデル（CLAP, EmbeddingGemma 2）がいずれも自己教師あり BEATs iter3 に届かず、「意味的埋め込みは機械音の微差に弱い」仮説と整合。CLAP は EmbeddingGemma 2 よりは良い
