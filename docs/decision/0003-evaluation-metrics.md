# 0003 評価指標の実装方針

- 日付: 2026-10-08
- ステータス: 採用

## 決定
公式 evaluator リポジトリをそのまま実行せず、同じ定義を `egaudio.evaluation.dcase_metrics` に移植しテストで固定する。
- AUC(domain) は当該ドメインの正常 + 全異常、pAUC は全クリップで `max_fpr=0.1`
- 集約は epsilon クリップ付き調和平均

## 理由
- 条件数（モード × 次元 × プール × スコアラ）が多く、ファイル出力を介さずメモリ上で評価したい
- 定義は短く、sklearn と一致することをテストで担保できる
