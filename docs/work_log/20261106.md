# 2026-11-06 作業ログ

## 実施内容（`feature/playground-app`）
- 会話のような発話音声の埋め込みがテキストにどれだけ近いかを試すため、ブラウザアプリを作成（[ADR 0007](../decision/0007-playground-gradio-app.md)、仕様は [design/playground](../design/playground/index.md)）
  - テキスト候補（1 行 1 候補）とマイク音声を入力すると、コサイン類似度・順位・候補平均との差を表示する
  - 起動: `docker compose run --rm --service-ports app uv run python scripts/app/run_playground.py` → http://localhost:7860
- 依存に gradio 6.31.0 を追加（グループ `app`）。既存パッケージのバージョンは変わっていない
- テスト: `tests/playground/` に 21 件追加し、全 112 件が成功
- 動作確認: 起動中のアプリに gradio_client で 2 秒の 440Hz 正弦波を送り、最後まで処理されることを確認。候補「今日はいい天気ですね」0.748 >「ピーという電子音」0.729 となり、正弦波でも発話文のほうが近くなった（モダリティギャップとハブ化の影響と思われる）

## 追加（2026-11-07）: 例文をビジネス向けに変更
- 初期の例文を、社内ナレッジ風の 10 文に差し替え（経営会議の時間、有給休暇の申請方法、案件の PM、経費精算の締め切りなど）。音声で質問し、答えになる文書が上位に来るかを見る想定
- テキストのプレフィックスに `document`（`title: none | text: {text}`、モデル同梱の文書用プロンプト）を追加し、既定値にした
