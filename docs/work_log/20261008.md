### 考察
- BEATs iter3 は公式 MAHALA をわずかに上回り、EmbeddingGemma 2 より明確に良い（+0.06）。ドメイン内 AUC も ToyCar・valve・gearbox で 0.7 前後まで上がり、**正常/異常の情報は BEATs には残っている**
- ラベル情報が強くなるほど（iter3 → +AS2M → FT）official score は下がり、ToyCar ではスコアのドメイン識別 AUC が 0.85 → 0.94 → 0.97 と上昇。意味的な学習ほど「動作条件の違い」に敏感になり target AUC が落ちる傾向で、計画時の仮説と整合
- ただし BEATs 変種間の差（0.01〜0.02）は、各機種 200 クリップ・単一実行のため有意とは言えない
- どのモデルでも公式 AUC(target) はドメイン内 AUC より大きく低い → **ドメインずれの補正が最大の改善余地**

## 追加: ESC-50 音声⇔音声検索によるモデル比較（`feature/step1b-esc50-retrieval`）

### 実施内容
- 公式 5 fold 交差検証で、4 fold を検索対象・1 fold をクエリにした k-NN 分類 / Precision@k / 線形プローブを実装・実行（全 5 モデル）

### 結果（5 fold 平均 ± 標準偏差, %）
| モデル | k-NN@1 | k-NN@5 | Precision@10 | 線形プローブ |
|---|---|---|---|---|
| EmbeddingGemma 2 | 70.2 ± 2.3 | 72.7 ± 2.4 | 56.6 ± 1.0 | 81.8 ± 1.3 |
| BEATs iter3 | 72.0 ± 2.1 | 70.6 ± 2.6 | 51.6 ± 1.5 | 88.3 ± 2.2 |
| BEATs iter3 L6 | 68.4 ± 2.6 | 67.7 ± 2.2 | 48.9 ± 1.6 | 86.2 ± 2.1 |
| BEATs iter3+ AS2M | 91.6 ± 2.3 | 90.8 ± 2.1 | 81.6 ± 0.5 | 95.9 ± 1.2 |
| BEATs iter3+ AS2M FT | 95.2 ± 0.9 | 95.6 ± 0.7 | 91.9 ± 0.5 | 96.6 ± 0.9 |
| （参考）EmbeddingGemma 2 ゼロショット | Top-1 27.4 | | | |

### 考察
- **EmbeddingGemma 2 の音声埋め込み自体はクラス情報をかなり持っている**（k-NN 70%, 線形プローブ 82%）。ゼロショット 27% との差は大きく、ESC-50 での弱さは主に**音声⇔テキストの対応付け側**にある
- ラベル不使用の BEATs iter3 と比べると k-NN はほぼ同等（@1 は全 fold で iter3 が 0〜3.5pt 上）、Precision@10 は EmbeddingGemma 2 が上、線形プローブは iter3 が 6.5pt 上
- AudioSet ラベル由来の BEATs（+AS2M, FT）は 90% 超。ESC-50 のクラスは AudioSet と重なるため有利な条件である点に注意
- DCASE とあわせると: EmbeddingGemma 2 は「何の音か」の検索では自己教師あり BEATs と同程度だが、同一機械内の正常/異常の微差では BEATs に劣る

### 実施内容

### 分かったこと
- **ESC-50 ゼロショットは予測が一部のテキストラベルに集中する**（各クラス正解 40 本に対し engine 209 回, wind 199, laughing 175, mouse_click 167 回予測）。rooster, rain, sea_waves など 11 クラスは一度も予測されず、17 クラスが再現率 0%。同じクラスでも音声 k-NN では 70〜95% 取れており、音声⇔テキスト対応側の偏り（ハブ化）が主因
- 大分類で見ても、ゼロショットは Animals の 40% を Human non-speech に誤分類（rooster/cat → crying_baby など）。k-NN では各大分類 80〜88%
- DCASE を 90% 分位点閾値で判定すると、EmbeddingGemma 2 は異常の大半を見逃す（平均 recall: source 0.17 / target 0.29）。BEATs iter3 は 0.39 / 0.51。ToyCar target で BEATs は異常 50/50 を検出する一方、EmbeddingGemma 2 は ToyCar target で正常の 64% を異常と誤判定（ドメインずれ）
