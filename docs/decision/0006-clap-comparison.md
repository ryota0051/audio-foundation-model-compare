# 0006 CLAP を比較対象に追加

- 日付: 2026-10-08
- ステータス: 採用

## 背景
BEATs はテキスト非対応のため、EmbeddingGemma 2 のゼロショット性能（27〜30%）が「音声⇔テキスト汎用モデルとして低いか」を判断できなかった。

## 決定
- 音声⇔テキスト対照学習モデル CLAP（`laion/larger_clap_general`, Apache 2.0, 776MB）を 1 モデルだけ追加し、ゼロショット・ESC-50 検索・DCASE の全実験で比較する
- 入力サンプリングレートをモデル設定ごとに持たせる（CLAP は 48kHz）。データセット設定の `target_sr` は廃止
- 10 秒超の音声はランダム切り出しを避け、決定的な窓分割 + 平均で埋め込む
- テンプレートは CLAP の標準書式（`This is a sound of {label}.`）を両モデル共通に評価し、書式の差で比較が歪まないようにする
- 設定の継承で EmbeddingGemma 専用のプレフィックスを外すため、`_replace: true` で辞書を丸ごと置き換えられるようにした

## 注意（ESC-50 の学習データ重複）
LAION-CLAP 論文（arXiv:2211.06687）は、学習データとゼロショット評価セットの重複に気付き、**評価セット側から重複サンプルを除いて**評価したと記載（ESC-50 は FSD50K-train と 399 件、Clotho-train と 94 件の重複を報告。報告ゼロショット精度 89.1%）。学習データ（LAION-Audio-630K の Freesound 約 51.5 万件）からは除かれていない。本リポジトリは ESC-50 全 2,000 本で評価しており、`larger_clap_general` はその後さらにデータを増やしたモデルのため、**ESC-50 の CLAP の値は学習時に見たクリップを含む可能性があり、楽観的な上限として扱う**。EmbeddingGemma 2 は学習データが非公開のため同様の確認はできない。
